# Task: Bump da versão do app para v1.4.5

## Objective
Passar a versão do app Monet de 1.4.4 para 1.4.5, executada pelo buildAgent, preparando o release das alterações das tasks anteriores (mover notas/cadernos, "Save web sources", caderno no Calendar).

## Context
- App desktop Tauri 2 + React 18 + TypeScript; working tree contém as mudanças aprovadas e revisadas da task anterior (não commitadas).
- A versão de release do app está declarada em `src-tauri/tauri.conf.json` (hoje `"version": "1.4.4"`).
- `package.json` e `src-tauri/Cargo.toml` estão em `0.1.0` e historicamente não acompanham a versão de release (commit recente "chore: aletrado versao" alterou apenas a versão do app).

## Requirements
- Atualizar a versão do app para **1.4.5** em todos os lugares onde a versão de release é declarada, seguindo as convenções do buildAgent para build/versão.
- Executar o procedimento de build/verificação definido no behavior do buildAgent, garantindo que o app builda com a nova versão.

## Constraints
- Não alterar código-fonte funcional — apenas o que for necessário para o bump de versão e build.
- Não commitar nem empurrar nada (working tree já contém mudanças não commitadas da task anterior); qualquer ação de commit/publicação só com instrução expressa do Coordenador.

## Edge Cases
- Se o build revelar que a versão precisa ser propagada para outros arquivos (ex.: lockfiles), propagar de forma consistente com a convenção existente.
- `latest.json` na raiz (updater) pode referenciar a versão anterior: só atualizar se for artefato gerado pelo build, não editar à mão.
