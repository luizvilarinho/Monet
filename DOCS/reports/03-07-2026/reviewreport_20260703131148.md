## src/App.tsx

### 1. Correção
Faz o que foi pedido. Todos os Requirements, Constraints e Edge Cases do Task Report foram verificados no diff:

- **Injeção em todos os comandos**: `datedNotesContext` é passado nos três ramos de `buildUserMessage` (`/docs`, `/week` e default), cobrindo inclusive os ramos em que `noteContent` vai vazio. OK.
- **Exclusão do próprio Calendar**: `getDatedNotes` pula notas com `notebookId === CALENDAR_NOTEBOOK_ID`. OK.
- **Sanitização**: mesmo pipeline do `/week` — `stripCommandLines(stripEmbedBlockTags(...)).trim()`, descartando resultado vazio. OK.
- **Fora do Calendar nada muda**: o bloco só executa quando `activeNote?.notebookId === CALENDAR_NOTEBOOK_ID` e `parseCalendarTitle` retorna data válida; caso contrário `datedNotesContext` fica `undefined` e `buildUserMessage` ignora o parâmetro. OK.
- **Sem novas chamadas ao banco**: usa apenas `notes` em memória. OK.
- **System prompt intocado**: confirmado. OK.
- **Formato/timezone de data**: `parseCalendarTitle` constrói `Date` com componentes locais e `toIsoDate` extrai `getFullYear/getMonth/getDate` (locais). Não usa `toISOString()`, então não há deslocamento de dia por timezone. Conversão DD/MM/YYYY → YYYY-MM-DD correta. OK.
- **Nota sem título**: fallback `'Untitled'`. OK.
- **`note.date` ausente/null**: `note.date !== isoDate` trata `undefined`/`null` corretamente (nunca igual à string ISO). OK.
- **Dependências do `useCallback`**: `notes` já estava no array de deps de `handleCommand` (linha 779) por causa do `/week`; nenhuma dep nova era necessária. OK.
- **Nenhuma nota datada no dia**: `getDatedNotes` retorna `[]`, `datedNotesContext` fica `undefined`, comando funciona como hoje. OK.

Nenhum bug encontrado.

- `[nit]` **Tensão de spec (para conhecimento do Orquestrador, não é erro do codeAgent)**: o system prompt instrui `/docs` a responder "using exclusively the 'Relevant document excerpts'" e `/week` "using exclusively the 'Calendar notes from the last 7 days' block". Para esses dois comandos, o modelo tende a ignorar o bloco "Notes tagged with this date" injetado, por instrução explícita do próprio system prompt. A implementação segue exatamente o que o Task Report pediu (injetar em todos os comandos sem alterar o system prompt), mas o efeito prático em `/docs` e `/week` pode ser nulo. Se o Coordenador quiser que o bloco seja considerado nesses comandos, será necessária uma task futura ajustando o system prompt.
