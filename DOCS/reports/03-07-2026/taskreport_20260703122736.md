# Task: Incluir notas datadas no contexto dos slash commands do Calendar

## Objective
Quando o usuário executar qualquer slash command dentro de uma nota diária do notebook Calendar (ex.: nota "03/07/2026"), as notas de outros cadernos sinalizadas com aquela mesma data (campo `date`) devem ser incluídas no contexto enviado ao modelo — da mesma forma que hoje já aparecem como cards na visão do dia.

## Context
- `src/App.tsx` — `handleCommand` monta o contexto dos comandos (`buildUserMessage`); já existe padrão análogo em `getWeekCalendarNotes`/`formatWeekContext` usado pelo `/week`. Helpers `formatCalendarTitle`/`parseCalendarTitle` convertem título da nota diária (DD/MM/YYYY) em `Date`.
- `src/lib/commands.ts` — definição dos slash commands (`COMMANDS`).
- Notas possuem campo `date?: string | null` (formato ISO `YYYY-MM-DD`, vindo de `<input type="date">` em `src/components/Editor/Editor.tsx`).
- O notebook Calendar é identificado por `CALENDAR_NOTEBOOK_ID` (persistido em localStorage).

## Requirements
- Ao executar qualquer slash command em uma nota cujo notebook é o Calendar e cujo título é uma data válida (DD/MM/YYYY), buscar todas as notas com campo `date` correspondente àquele dia e injetar título + conteúdo delas no user message enviado ao modelo, em um bloco identificado (ex.: "Notes tagged with this date").
- O comportamento vale para todos os comandos de `COMMANDS`, incluindo `/week` (que continua agregando os últimos 7 dias de notas do Calendar) e `/docs`/`/summarize`/`/action` etc.
- O conteúdo das notas datadas deve passar pela mesma sanitização já usada no `/week` (`stripCommandLines` + `stripEmbedBlockTags`).
- Fora do notebook Calendar, nada muda no comportamento atual dos comandos.

## Constraints
- Não alterar o system prompt global; a injeção acontece no user message, seguindo o padrão já existente (`ragContext`, `searchContext`, `weekContext`).
- Não criar novas chamadas ao banco: as notas já estão carregadas em memória (`notes` de `useNotes`).
- Manter o padrão de código e idioma (inglês) do restante do app.

## Edge Cases
- Nenhuma nota sinalizada com a data → comando funciona exatamente como hoje (sem bloco extra, sem erro).
- Nota datada com conteúdo vazio após sanitização → ignorar.
- Nota diária do Calendar com título que não é data válida → sem injeção (comportamento atual).
- Nota datada muito extensa → incluir integralmente por ora (mesmo comportamento do `/week`); sem truncamento nesta task.
- Notas do próprio Calendar não entram no bloco de notas datadas (apenas notas de outros cadernos com o campo `date`).
