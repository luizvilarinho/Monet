# Task: Suporte a EPUB — Fase A (importação, banco, tipos e CSP)

> **Esta é a primeira de duas tasks.** A Fase B (`EpubReader.tsx` — render, navegação, grifos, chat, citação) vem depois, em task própria. A separação é deliberada: a Fase A mexe em código existente e validado (storage, tipos, Library, CSP), enquanto a Fase B é componente novo. Isolando as duas, uma regressão no leitor de PDF aponta para uma causa só.

## Objective

Preparar o app para aceitar arquivos EPUB: import, persistência, tipos e CSP. Ao final desta task o usuário consegue importar um `.epub`, vê o livro na Library com título/autor corretos e um selo de formato — mas **ainda não consegue abrir**, porque o leitor é da Fase B. Abrir um EPUB deve exibir uma mensagem clara, nunca um erro cru ou tela quebrada.

## Context

**Decisões de arquitetura já fechadas** (não reabrir — o porquê está em `DOCS/reports/07-08-2026/executionreport_20260807190451.md`):
- **Tabela única** para os dois formatos, com `ADD COLUMN` — sem tabela separada para EPUB, sem rebuild de tabela.
- **`page` é um ordinal de leitura para os dois formatos**: número de página no PDF, índice de *location* no EPUB. É por ele que `useHighlights.orderedHighlights` ordena.
- **Reader separado na Fase B**; `Reader.tsx` (PDF) permanece intacto.
- **Citação em EPUB = nome do capítulo + porcentagem**, com o **título vindo do TOC** (nunca um número gerado por nós — o TOC inclui capa e pré-textual). Fallback para só porcentagem quando não houver TOC utilizável.
- **Busca full-text fica FORA** do EPUB (v2).

**Evidência do spike** (`DOCS/reports/07-08-2026/explorerreport_20260807202000.md`) — medida com `@likecoin/epubjs@0.3.93`, já instalado:
- `blob:` na CSP é **obrigatório**: sem ele as imagens do EPUB são bloqueadas (`img-src bloqueou blob`). O texto renderiza normalmente mesmo sem.
- `locations.generate(1600)` ≈ 175 ms → 355 locations; `locations.save()` ≈ 28,9 KB.
- Sandbox do iframe já vem `allow-same-origin` **sem** `allow-scripts`; script embutido não executa.

**Arquivos no escopo:**
- `src-tauri/src/books.rs` — filtro e extensão do import
- `src-tauri/src/lib.rs` — nova migration (**a última existente é a versão 15**, `documents_origin`)
- `src-tauri/tauri.conf.json` — CSP
- `src/types/index.ts` — união discriminada de `Book`
- `src/lib/epub.ts` (novo), `src/lib/books.ts`
- `src/storage/tauri.ts`, `src/storage/index.ts`, `src/storage/browser.ts`
- `src/components/Library/Library.tsx`
- `src/components/Reader/QuoteToNoteModal.tsx` + `src/lib/bookQuotes.ts` (ver requisito 8)

## Requirements

1. **Import no Rust** (`books.rs`): aceitar `.epub` além de `.pdf` no filtro do dialog e na checagem de extensão; o destino deve **preservar a extensão original** em vez do `.pdf` fixo de hoje (`books.rs:69`). Teto de 50 MB continua valendo para ambos.

2. **CSP** (`tauri.conf.json`): adicionar `blob:` a `default-src`, `style-src`, `img-src` e `font-src`, e incluir `frame-src 'self' blob:`. **`script-src` NÃO recebe `blob:`** — é o que impede script embutido em EPUB de terceiro de executar. Não remover nada do que já existe.

3. **Migration nova** (versão 16), só com `ADD COLUMN` (sem rebuild):
   - `books.format TEXT NOT NULL DEFAULT 'pdf'`
   - `books.cfi TEXT` (nulo; posição exata de retomada no EPUB)
   - `books.locations_json TEXT` (nulo; cache do `locations.save()`)
   - `book_highlights.cfi TEXT` (nulo; âncora real do grifo no EPUB)
   Manter o comentário no padrão das migrations vizinhas, registrando que a tabela é de propriedade exclusiva do frontend.

4. **Tipos** (`src/types/index.ts`): transformar `Book` em união discriminada por `format`, com base comum e os campos específicos de cada formato. O objetivo é que o compilador obrigue cada consumidor a tratar os dois casos — é isso que substitui a separação de tabelas.

5. **`src/lib/epub.ts`** (novo, espelhando o papel de `src/lib/pdf.ts`): abrir o EPUB a partir de bytes, extrair título/autor do OPF, gerar e serializar as locations. Concentrar aqui todo uso do `@likecoin/epubjs` — nenhum outro módulo deve importar a lib direto.

6. **`importBook`** (`src/lib/books.ts`): ramificar por extensão. No caminho EPUB, extrair metadados, gerar locations, e gravar `totalPages` = nº de locations, `lastPage` = 1, `locationsJson` = cache. Preservar o comportamento atual de **rollback**: se o arquivo for inválido, desfazer a cópia antes de qualquer insert, para nunca registrar livro órfão (`books.ts:43-56`).

7. **Storage**: `rowToBook` passa a montar a união a partir de `format`; `saveBook` grava as colunas novas. Manter o clamp defensivo existente de `lastPage` (`tauri.ts:169`).

8. **Rótulo de posição na citação** — preparação para a Fase B:
   - `buildQuoteBlock` troca o parâmetro `page: number` por `label: string` já formatado. Os 3 chamadores passam a montar o rótulo; **no PDF continua `p. ${page}`, e a saída atual deve ficar byte a byte idêntica**.
   - **Mover `buildQuoteBlock` e `appendQuoteToContent` para `src/lib`** (são funções puras de string, sem React). Isso inverte a seta de dependência e resolve o achado do `codereviewAgent`: hoje `src/lib/bookQuotes.ts` é o único arquivo de `src/lib` que importa de `components`. Fazer na mesma alteração, sem shim de re-export.

9. **Library** (`Library.tsx`): textos deixam de ser PDF-only (`:185` "+ Import PDF", `:217` "Import a PDF to start reading"); adicionar selo de formato na listagem; e **abrir um EPUB deve mostrar mensagem clara de "ainda não disponível"**, não erro nem tela quebrada.

10. **Validação**: `npm run build` sem erros novos. Importar o EPUB de teste e confirmar no banco que `format`, `total_pages` (= nº de locations) e `locations_json` foram gravados. Confirmar que importar e abrir um PDF continua funcionando exatamente como antes.

## Constraints

- **O leitor de PDF não pode mudar de comportamento.** É o critério de aceite mais importante desta task.
- **Não criar o `EpubReader.tsx`** nem nada de render de EPUB — é a Fase B.
- **Não implementar busca** para EPUB (decisão: v2).
- **Não implementar resolução de capítulo pelo TOC** — é da Fase B, junto com o leitor. Esta task só prepara a assinatura (`label: string`).
- Não mexer em toolbar, painel Summary/Highlights, debounce de página/zoom, controlador de seleção.
- Nunca passar `forceXMLDom: true` ao epubjs: é o único caminho que acorda o `@xmldom/xmldom` vulnerável, hoje inerte porque o browser usa `DOMParser`/`XMLSerializer` nativos.
- **Fixar `@likecoin/epubjs` em `0.3.93` exato** (sem `^`): o `dist-tags.latest` do pacote aponta para uma prerelease (`0.3.94-beta.0`), então uma instalação limpa pode não resolver igual à que foi medida no spike.
- Padrão do repo: comentários em português explicando o *porquê*, strings de UI em inglês.

## Edge Cases

- **EPUB com DRM** (`META-INF/encryption.xml` presente): não abre por nenhuma biblioteca open source. Deve falhar no import com mensagem clara e **acionar o rollback da cópia**, igual ao caminho do PDF protegido por senha.
- **EPUB corrompido / zip inválido**: mesma mensagem amigável + rollback.
- **EPUB sem `dc:title` ou `dc:creator`**: cair no nome do arquivo, como o PDF já faz (`books.ts:60`).
- **Livros já existentes no banco** (gravados antes desta migration): têm que continuar abrindo. O `DEFAULT 'pdf'` cobre, mas o `rowToBook` precisa tolerar `format` nulo/ausente por segurança.
- **Extensão em maiúsculas** (`.EPUB`): a checagem atual do PDF já usa `eq_ignore_ascii_case` (`books.rs:50`) — manter esse comportamento para os dois formatos.
- **Colisão de nome**: o destino usa UUID, então não há colisão — mas a extensão agora é variável e o `books_read_file`/`books_delete_file` validam por diretório, não por extensão. Confirmar que seguem funcionando.
- **`locations.generate()` em livro grande** pode levar alguns segundos: o import deixa de ser instantâneo. Garantir que a UI não pareça travada durante o import.
