# Task: Fase 2 do Leitor de Livros — Grifos e Citações

## Objective

Adicionar ao leitor de PDF (Fase 1, já entregue na branch feature/ebook-reader) as ferramentas de trabalho do leitor: grifar trechos do texto com cores, gerenciar os grifos em um painel lateral e copiar citações para os cadernos do Monet com fonte e página. Os grifos e as citações devem ser persistidos com data de criação, pois na Fase 3 serão o contexto do chat de IA do leitor (do mais recente ao mais antigo). Visão de produto em `DOCS/specs/productVision.md`: os grifos e citações são o "esforço de elaboração" do usuário — o centro da experiência.

## Context

- Leitor existente: `src/components/Reader/Reader.tsx` (pdfjs 5.6, canvas + TextLayer já ativa — a seleção de texto já é possível; grifos serão desenhados sobre/sob a text layer).
- Biblioteca: `src/components/Library/Library.tsx`; tabela `books` (Migration v12) e comandos Rust de arquivo em `src-tauri/src/books.rs`.
- Persistência: novas tabelas no `monet.db` seguindo o padrão da camada `src/storage/` (propriedade exclusiva do frontend via plugin-sql, Row snake_case + rowToX + upsert + scheduleCheckpoint) — próxima migration em `src-tauri/src/lib.rs`.
- Cópia para caderno: notas são documentos Tiptap gerenciados por `src/hooks/useNotes.ts` / `useNotebooks.ts`; referência de UX para "salvar em nota" existente: `src/components/ChatPanel/SaveToNoteModal.tsx`.

## Requirements

- **Seleção → toolbar flutuante**: ao selecionar texto na text layer do leitor, exibir uma toolbar flutuante próxima à seleção com as ações: grifar (escolha entre um conjunto pequeno de cores, ex.: 3–4), copiar texto (clipboard) e copiar citação para caderno.
- **Grifos persistidos**: nova tabela `book_highlights` com, no mínimo: `id`, `book_id`, `page`, `text` (trecho grifado), `color`, posição (retângulos em coordenadas normalizadas da página, independentes de zoom), `created_at`. Grifos de um livro são carregados ao abrir o livro e desenhados nas páginas correspondentes.
- **Grifos re-renderizam corretamente** ao trocar de página e ao mudar o zoom (posições recalculadas a partir das coordenadas normalizadas).
- **Remover grifo**: clicar em um grifo na página oferece a remoção (e mostra a data de criação).
- **Painel lateral de grifos**: painel toggle no leitor listando os grifos do livro (trecho, cor, página, data), ordenado por página ou por data (escolher um padrão e manter simples); clicar em um item navega até a página do grifo. Contador ou indicação de grifos por página é bem-vindo, mas não obrigatório.
- **Copiar citação para caderno**: a ação abre um modal para escolher caderno e nota (padrão do SaveToNoteModal: nota existente ou nova), e insere o trecho na nota como blockquote seguido da fonte — título do livro e página (ex.: "— *Título*, p. 42").
- **Citações registradas**: nova tabela `book_quotes` registrando cada citação copiada: `id`, `book_id`, `page`, `text`, `target_note_id` (nullable — a nota pode ser apagada depois), `created_at`. Sem UI de gestão nesta fase (é insumo para o contexto da IA na Fase 3); a cópia simples para clipboard NÃO gera registro.
- **Cascata na remoção do livro**: deletar um livro remove seus grifos e citações registradas.
- UI em inglês, consistente com o restante do app.

## Constraints

- Não implementar nesta fase: chat de IA no leitor, indexação na Knowledge Base, anotações de margem (comentários em grifos), exportação de grifos. Fase 2 é somente grifos + citações.
- Seguir os invariantes do projeto: tabelas novas com dono único (frontend via plugin-sql), `scheduleCheckpoint()` após escrita, sem mudanças de CSP/capabilities, comandos Rust apenas se estritamente necessário (a expectativa é não precisar de Rust nesta fase).
- Grifo é restrito a uma página (a text layer é por página); seleção atravessando páginas não é suportada — grifar apenas a parte da página atual ou orientar o usuário.
- Não degradar a performance do leitor: desenhar grifos não pode re-renderizar o canvas do PDF; usar camada própria (divs absolutas sobre a página).
- Reusar padrões existentes (CSS Modules, useConfirm para remoções, estrutura do SaveToNoteModal para o modal de citação). Dead code encontrado no caminho deve ser removido.

## Edge Cases

- PDF escaneado (sem text layer): seleção não existe — o leitor continua funcionando; painel de grifos mostra vazio; nenhuma quebra.
- Seleção que cruza múltiplos spans da text layer (linhas/colunas): os retângulos do grifo devem cobrir a seleção real (múltiplos rects), não um bounding box gigante.
- Zoom alterado entre criar e re-exibir o grifo: posições normalizadas garantem que o grifo continua sobre o texto certo.
- Grifos sobrepostos (usuário grifa duas vezes o mesmo trecho): permitido, sem corromper a renderização; remoção age sobre o grifo clicado.
- Citação para nota que foi apagada depois: o registro em `book_quotes` permanece válido (target_note_id órfão não pode quebrar nada).
- Trecho selecionado muito longo (várias páginas de texto em uma página densa): aceitar, mas truncar com aviso se exceder um limite razoável para o blockquote.
- Seleção vazia ou apenas espaços: toolbar não aparece / ações desabilitadas.
- Livro com arquivo ausente (erro já tratado na Fase 1): painel de grifos não deve quebrar nem apagar dados.
