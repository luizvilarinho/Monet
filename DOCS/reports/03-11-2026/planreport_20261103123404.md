### Etapa 2 — R2 (base): casamento de datas de nota em `src/lib/agenda.ts`
- Status: PENDENTE

- Descrição: módulo de funções puras, sem storage nem React. Conteúdo desta etapa:
  ```ts
  export type NoteDateKind = 'date' | 'calendar' | 'property'
  export interface NoteDateField { kind: NoteDateKind; name: string; date: string } // date = YYYY-MM-DD
  export interface NoteDateMatch { matched: NoteDateField[]; other: NoteDateField[]; ongoing: boolean }
  export function noteDateFields(note: Note, defs: MetadataDef[]): NoteDateField[]
  export function matchNoteDates(note: Note, defs: MetadataDef[], from: string, to: string): NoteDateMatch | null
  export function formatNoteDateMatch(m: NoteDateMatch): string
  export function withWeekday(key: string): string // '2026-11-06 (Friday)'
  ```
  Regras:
  - `noteDateFields`: (a) `note.date` válido (`/^\d{4}-\d{2}-\d{2}$/`) → `{kind:'date', name:'Date'}`; (b) nota do caderno Calendar com `parseCalendarTitle(title)` válido → `{kind:'calendar', name:'Daily note'}`; (c) cada def de `typeDefs(defs, note.typeId)` (de `src/lib/noteTypes.ts`: só o tipo **atual**, scope `note`) com `type === 'date'` e valor string ISO em `note.properties[def.id]` → `{kind:'property', name: def.name}`. Valores guardados de outro tipo não contam.
  - `matchNoteDates`: `matched` = campos com `from <= date <= to`; `other` = os demais. Com `matched` não vazio → `{ matched, other, ongoing:false }` (nota arquivada pode casar; quem chama decide se a quer). Sem `matched`: **ongoing** só se a nota não está arquivada, tem **2 ou mais** campos `property`, o menor < `from` e o maior > `to` (ignora `note.date` e o título do Calendar — regra do explorer adotada pelo Orquestrador) → `{ matched:[], other: <campos property ordenados por data>, ongoing:true }`. Senão `null`.
  - `formatNoteDateMatch`: não-ongoing → `matched` como `Name: 2026-11-06 (Friday)` unidos por ` · `, mais ` (also: Name 2026-11-17)` com os `other` quando houver; ongoing → `ongoing: <1º property> <data> → <último property> <data>` (ex.: `ongoing: Início 2026-10-25 (Saturday) → Fim 2026-11-17 (Monday)`).
  - `withWeekday`: `getWeekdayName(new Date(y, m-1, d))`.
  - Comentários em português curtos, no padrão do projeto.

  ```ts

  // nodes de bloco custom do editor).
  const BLOCK_TAGS = new Set(['P', 'DIV', 'UL', 'OL', 'LI', 'BLOCKQUOTE', 'PRE', 'TABLE', 'THEAD', 'TBODY', 'TR', 'TD', 'TH', 'HR', 'H1', 'H2', 'H3', 'H4', 'H5', 'H6', 'EMBED-BLOCK', 'LINKED-NOTE', 'TASKS-QUERY', 'TOGGLE-BLOCK'])

  function hasInlineNeighbor(br: Element, dir: 'previousSibling' | 'nextSibling'): boolean {
    let n = br[dir]
    while (n) {
      if (n.nodeType === Node.TEXT_NODE) {
        if (n.textContent?.trim()) return true
      } else if (n.nodeType === Node.ELEMENT_NODE) {
        const tag = (n as Element).tagName
        if (tag !== 'BR') return !BLOCK_TAGS.has(tag)
      }
      n = n[dir]
    }
    return false
  }

    if (br.closest('p')) return false
    const parent = br.parentElement
    if (parent && parent !== root && !BLOCK_TAGS.has(parent.tagName)) return false
    return !hasInlineNeighbor(br, 'previousSibling') && !hasInlineNeighbor(br, 'nextSibling')
  ```
