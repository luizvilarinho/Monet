# Plano — Controle de margem lateral no leitor de EPUB

## Escopo
Adicionar um controle de margem lateral (esquerda/direita simétricas) ao leitor de EPUB, aplicado como `paddingLeft`/`paddingRight` inline no container `.viewerSurface`. Estado persistido globalmente em `localStorage`, mesmo padrão da diagramação (`spreadMode`). UI espelha exatamente o grupo `.fontControls` existente. - Descrição: Adicionar no topo do componente `EpubReader.tsx` (junto de `SPREAD_MODE_KEY`, ~linha 110) as constantes da margem e a leitura inicial do `localStorage`. Criar o estado `marginPx` com `useState`, inicializando de `localStorage.getItem(MARGIN_KEY)` e validando com um `clampMargin` que arredonda para o passo (mesma ideia do `clampFontScale`, mas para inteiros).   - Constantes:
    - `MARGIN_KEY = 'monet:epub-reader-margin'`
    - `MIN_MARGIN_PX = 0`
    - `MAX_MARGIN_PX = 160`

  - Helper: `clampMargin(raw: number): number` que faz `Math.min(MAX, Math.max(MIN, raw))`, depois `Math.round(raw / STEP) * STEP` para garantir passo, e retorna inteiro.
  - Estado: `const [marginPx, setMarginPx] = useState<number>(() => { try { const raw = localStorage.getItem(MARGIN_KEY); if (raw == null) return DEFAULT_MARGIN_PX; const n = Number(raw); return Number.isFinite(n) ? clampMargin(n) : DEFAULT_MARGIN_PX; } catch { return DEFAULT_MARGIN_PX; } })`.
  - Função `changeMargin(next: number)`: aplica `clampMargin`, se igual ao atual retorna, senão `setMarginPx`.

## Notas para o codeAgent
- **Não** separar margem esquerda/direita — o requisito fala em "margem lateral" (singular, comprimento de linha). Default esperado em leitores de EPUB é simetria.
- **Não** mexer no `EpubReader.module.css` — `.fontControls` e `.fontLabel` já existem e dão a aparência correta; duplicar classes seria CSS morto.
- **Não** criar coluna no schema do banco — a persistência é localStorage, mesma justificativa do `spreadMode` (preferência global de layout, não estado do livro).
- **Não** adicionar debounce — uma única chave inteira não precisa. Padrão do `spreadMode` é referência mais próxima que o do `zoom`.
- **Não** chamar `displayEpubAt` em `changeMargin` — o `ResizeObserver` cuida. Chamar de novo seria trabalho redundante e competiria com o ciclo de resize.
- **Não** alterar `src/lib/epub.ts` — a fronteira do epubjs não precisa mudar; o ajuste é puramente no container externo.
- A faixa 0–160 passo 16 dá 11 níveis (0,16,32,…,160). Botão `−` desabilita em 0, `+` em 160.
- Edge case de janela estreita: com `min-width: 0` no `.viewer` e `max-width: 860px` no `.viewerSurface`, o flex já encolhe — não precisa de clamp adicional nesta entrega. Se a janela ficar muito estreita, o usuário vê o texto estreitar progressivamente, comportamento aceitável.
