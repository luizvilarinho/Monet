## `src/components/Toolbar/Toolbar.tsx`

Novo botão "preview" ao lado de "export .md".

- **Padrões / Organização** `[importante]`: o botão usa `className={previewMode ? styles.exportSuccess : styles.actionBtn}`. `exportSuccess` é a classe semântica do botão de export que pisca verde mostrando "saved!". Reaproveitar essa classe para indicar "preview ativo" é incorreto semanticamente, confunde a intenção do CSS (qualquer mudança futura no estilo de "saved!" afetará o botão de preview) e fere o padrão de nomes de classes por responsabilidade. Deveria haver uma classe própria (ex.: `previewActive` ou reusar `actionBtn` com o seletor `aria-pressed="true"` já existente em `Toolbar.module.css:114` — `.actionBtn[aria-pressed="true"]` já está estilizado com a cor de accent). Hoje o `aria-pressed` é inefetivo porque a classe base troca.
- **Efeitos colaterais** `[nit]`: o texto do botão inverte de `preview` (modo normal) para `editing` (modo preview ativo). É confuso: quando o preview está ATIVO, o rótulo diz "editing" (que sugere o oposto). A intenção parece ser "clique para voltar a editar", mas lê-se como "você está editando". Sugestão: manter `preview` sempre, ou usar `preview on` / `preview off`.
