# Task: Ajustes no Notebook — Preview, Tasks aninhadas, Calendário, Menu de contexto, Logs e Estudo de Tabelas

## Objective
Conjunto de 6 ajustes na funcionalidade de Anotações (Notebook) solicitados pelo Coordenador, visando melhorar a experiência de edição, visualização e rastreabilidade das notas.

## Context
- Editor baseado em TipTap v3 (`src/components/Editor/`).
- `App.tsx` atua como orquestrador principal (estado, handlers, wiring).
- `CalendarView.tsx` gerencia o calendário de notas diárias e notas "dated".
- `FormattingToolbar.tsx` contém a bubble menu de formatação (seleção de texto).
- Slash commands disparam LLMs via OpenRouter (`handleCommand` em `App.tsx` + `useAi.ts`).
- Padrões do projeto: CSS Modules, hooks customizados, adapter pattern no storage, comentários em PT-BR, `import.meta.env.DEV` para logs de desenvolvimento.

## Requirements

### 1. Botão Preview (ocultar slash commands)
- Botão "preview" ao lado do "export .md" na Toolbar.
- Ao acionar, oculta temporariamente as linhas de slash command (`/comando...`) do editor via decoração ProseMirror (`display: none`). Toggle — clicar novamente restaura.
- Em modo preview, slash commands ficam desativados: autocomplete não aparece e Enter não executa comandos.

### 2. Estudo de manuseio de tabelas
- Documento técnico com análise dos problemas atuais (copiar/colar trechos, mover tabela, reordenar linhas) e propostas de melhoria com prós/contras, esforço e recomendação.

### 3. Calendário — notas criadas/editadas no dia
- Ao clicar num dia do calendário, mostrar cards abaixo do grid com as notas criadas ou editadas naquele dia (de qualquer notebook, exceto o notebook Calendar).
- Notas "dated" (com `note.date` atribuído manualmente) aparecem com linha roxa; notas criadas/editadas no dia aparecem com linha verde. Sem duplicação.
- Indicador (ponto laranja) no dia atual quando há atividade.

### 4. console.log nos system prompts
- Rastrear via console os system prompts e user messages enviados ao modelo ao acionar slash commands, para depuração.

### 5. Hierarquia de tasks (Tab)
- Permitir criar tasks aninhadas (subtasks) usando Tab/Shift+Tab, com indentação visual e alinhamento correto do checkbox com o texto.

### 6. Menu de contexto (botão direito) com formatação
- Ao clicar com o botão direito no editor, menu flutuante na posição do clique com as opções de formatação (mesmos ícones da BubbleMenu).
- Ao selecionar uma opção, criar uma nova linha já com a formatação escolhida.
- Layout horizontal compacto, com posicionamento inteligente (flip vertical quando perto do fundo da tela).

## Constraints
- Não quebrar comportamento existente de notas, slash commands ou calendário.
- Seguir padrões do projeto (CSS Modules, `CALENDAR_NOTEBOOK_ID`, `import.meta.env.DEV` para logs).
- Cada tarefa testada individualmente (typecheck + build).

## Decisões do Coordenador (clarificadas via AskUserQuestion)
- **Preview**: apenas oculta slash commands no editor (toggle), sem modal/painel separado.
- **Tabelas**: apenas estudo técnico + proposta, sem implementação.
- **Calendário**: notas criadas/editadas aparecem como cards (linha verde) abaixo do calendário no dia selecionado; notas dated mantêm linha roxa; notas do notebook Calendar não aparecem na lista.
- **Menu de contexto**: aparece na posição do cursor com as formatações, criando nova linha formatada.

## Edge Cases
- Texto longo em task com checkbox: texto deve quebrar mantendo-se ao lado do checkbox (não cair para linha abaixo do `[ ]`).
- Parágrafos (`<p>`) dentro de tasks com margin padrão desalinhavam o texto do checkbox — corrigido com `margin: -2px 0`.
- Subtasks aninhadas precisam de `flex-wrap: wrap` + `flex-basis: calc(100% - 22px)` para alinhar checkbox e quebrar a `ul` filha para a próxima linha.
- Menu de contexto próximo à borda inferior/direita da tela precisa de flip/clamp para não ser cortado.
- Modo preview deve fechar autocomplete aberto e bloquear execução de comandos.
- Deduplicação de cards no calendário: nota tanto "dated" quanto "active" no mesmo dia aparece uma vez (prioridade dated/roxa).
