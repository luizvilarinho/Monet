# Task: Mincer — processador de grandes volumes (VOLP dentro do Monet)

## Objective
Trazer o VOLP (`C:\Users\User\Documents\projetos\Minuta\minuta`) para dentro do Monet como **Mincer**, o 4º item do menu principal (Notebook, Chat, Library, Mincer). O Monet é bom com pequenos volumes de informação; o Mincer cobre o gap dos grandes volumes: transcrever reuniões/gravações, resumir vídeos do YouTube, resumir artigos da web, capturar o texto de páginas, processar arquivos e texto colado. O resultado precisa entrar no fluxo do Monet: ir direto para um caderno ou para uma conversa no Chat.

## Context
- Monet: Tauri 2 + React 19 + Tiptap, SQLite (tauri-plugin-sql), RAG em `rag.rs`/`vec_db.rs`, Chat com sessões por contexto (Notebook, Library) — ver `DOCS/specs/PRD.md`, `DOCS/specs/systemSpecification.md`.
- VOLP: mesma stack + Tailwind. Entradas: arquivo, colar texto, gravação WASAPI (sistema + mic), YouTube (sidecar yt-dlp), página web (`dom_smoothie`). Transcrição: ffmpeg → MP3 16 kHz em pedaços de 20 min → OpenRouter `/audio/transcriptions` com retry e cache por pedaço. Resumo: uma chamada, presets Meeting/Class/News/Scientific. Saída em `dd-mm-yyyy_hh-mm-ss/{resumo.md, transcricao.md}`.
- Estudo prévio: `DOCS/features/central_informacao_study.md` (I13, D6 — contrato VOLP → Monet).
- O Coordenador pré-autorizou o pipeline inteiro (explorer → planner → code → review → uxAgent → ajustes → review) sem aprovações intermediárias; ele testa só no final.

## Requirements
- Novo item **Mincer** no menu principal, no mesmo nível de Notebook, Chat e Library.
- Portar as funcionalidades do VOLP: arquivo (áudio/vídeo/texto), colar texto, gravação (sistema + microfone), YouTube, página web (resumo e captura de texto puro), transcrição em pedaços com retomada, resumo com presets.
- Manter os botões de salvar em pasta escolhida pelo usuário (resumo e transcrição em `.md`).
- **Enviar para caderno**: o resumo (e opcionalmente a transcrição) vira nota num caderno escolhido pelo usuário.
- **Enviar para Chat**: abre uma conversa no Chat com o conteúdo do Mincer como contexto, para conversar sobre ele.
- No Chat, nova seção **Mincer** na lista de conversas, igual às de Notebook e Library.
- UI no padrão visual do Monet (não Tailwind se o Monet não usa), textos em inglês, ícones Phosphor.
- Chaves de API e modelos vêm das configurações existentes do Monet (OpenRouter), sem nova configuração duplicada.

## Constraints
- Seguir convenções do Monet (CSS existente, componentes, `src/storage`, comandos Rust em módulo próprio).
- Ícones sempre Phosphor, nunca emoji; ações importantes com rótulo escrito.
- Não usar BEGIN/COMMIT manual com tauri-plugin-sql.
- Sidecars (ffmpeg, yt-dlp) entram no bundle; atenção ao tamanho e ao MSIX da Microsoft Store.
- Remover dead code; não deixar código do VOLP sem uso.
- Projeto pré-lançamento: breaking changes de dados são aceitáveis, mas não quebrar dados existentes de notas/chat.

## Edge Cases
- Processo longo (horas de áudio): progresso visível, cancelamento, retomada após falha de um pedaço.
- Usuário sai da tela do Mincer durante o processamento: o trabalho não pode se perder.
- Falta de chave de API / sidecar ausente / YouTube sem áudio / página sem conteúdo legível.
- Resumo muito longo para o contexto do Chat — definir corte ou estratégia.
- Enviar para caderno quando não há cadernos; nota gerada com Markdown convertido corretamente no Tiptap.
- Gravação: permissão de microfone negada, nenhum dispositivo de saída.
