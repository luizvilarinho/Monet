Recomendação:
- `type TaskStatus = string`; manter `BUILTIN_STATUS` e helpers `isOpen/isClosed` por id (done = concluído, dropped = descartado, todo/doing e qualquer custom = aberto).
- Nova tabela `task_statuses` (id, name, color, sort_order, wip_limit NULL, builtin) criada em `ensureTasksTables` (`storage/tauri.ts:614-640`) com `CREATE TABLE IF NOT EXISTS` + seed `INSERT OR IGNORE` dos 4 built-in. Mesmo padrão idempotente já usado (migrations Rust não rodam em prod, ver comentário tauri.ts:351-355). Sem BEGIN/COMMIT.
- Excluir status: `UPDATE notebook_tasks SET status='todo' WHERE status=?` e depois DELETE, execuções separadas; atualizar state em memória. Ids por slug/nanoid, nunca reaproveitar nome; renomear só altera `name`.
- Guardar no SQLite (não localStorage) para main/Keep/assistant ficarem coerentes.
